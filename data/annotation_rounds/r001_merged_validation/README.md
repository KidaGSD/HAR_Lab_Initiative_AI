# r001_merged_validation

Minimal outputs kept in this folder:

- `round1_assigned_only_30000_with_validations.csv`
  - Main merged Round-1 CSV (30,000 rows preserved).
- `round1_validated_rows_with_decisions.csv`
  - Only matched validated rows with final verdict (`Gold`, `Bad`, `Skip`, `Delete Row`).
- `round1_deep_analysis_subset_unique_narration_final_action.csv`
  - Deep-analysis subset (~5k), deduped by normalized narration + final action (Gold/Bad only).
- `round1_merge_summary.json`
  - Merge counts and provenance metadata from the run.

Removed as non-essential:

- duplicate second-run files (`*_v2`)
- `round1_validated_rows_all_matched.csv`
- `round1_validation_conflict_log.csv`
- `round1_validation_unmatched_rows.csv`
- archive folder of second run

If needed, deleted QA logs can be regenerated by rerunning:

- `scripts/data_validation/merge_round1_validated_sources.py`
